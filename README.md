## Como executar

Não precisa compilar separadamente. Cada arquivo roda direto com `java Arquivo.java`.

Parte 1:

```
cd parte1-filosofos
java FilosofosIngenuo.java
java FilosofosHierarquia.java
```

Parte 2 :

```
cd parte2-semaforo
java ContadorSemSincronizacao.java
java ContadorComSemaforo.java
```

Parte 3:

```
cd parte3-deadlock
java DeadlockTravando.java
java DeadlockCorrigido.java
```
